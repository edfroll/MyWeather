# MyWeather

Нативное iOS-приложение погоды на Open-Meteo. **Витрина / портфолио: глубина важнее широты.**
Три акцента, которые делаются показательно (продукт §1.1): изолированный SPM-пакет `ChartKit`,
Swift 6 strict concurrency на CoreLocation, двухслойный кэш с догрузкой недостающих кусков.

## Рамки стека

- Minimum **iOS 17**, языковой режим **Swift 6**, Swift Testing, SwiftUI + Swift Charts (research §1).
- **API новее iOS 17 — только через `#available` с фолбэком.**
- **Скилл `swiftui-pro` считает базой iOS 27: его рекомендации проверять против правила выше.**

## Где что делается

- **Облако — треды проекта** (без Xcode, без сборки): архитектура, критика, ревью, docs, Jira.
- **Mac — Remote Control**, его запускает тред тикета: реализация, сборка, тесты.
- **Код приложения в облаке не пишется.** Исключение возможно только для пакета,
  тестируемого на Linux, если архитектор его выделит (roadmap §2, §4 п. 2).
- Скиллы репозитория в облачный тред не загружаются: роль запускается постановкой
  «прочитай и следуй `.claude/skills/mw-<роль>/SKILL.md`» (harness §1.2).

  проверка на устройстве, релиз. Стопа «перед коммитом» нет (harness §5).
- Одна сессия — одна роль или один тикет.
- Лимиты: при 50% пятичасового или недельного окна — стоп и вопрос Edward (harness §8).
