# MyWeather

Нативное iOS-приложение погоды на Open-Meteo. **Витрина / портфолио: глубина важнее широты.**
Три акцента, которые делаются показательно (продукт §1.1): изолированный SPM-пакет `ChartKit`,
Swift 6 strict concurrency на CoreLocation, двухслойный кэш с догрузкой недостающих кусков.

## Рамки стека

- Minimum **iOS 17**, языковой режим **Swift 6**, Swift Testing, SwiftUI + Swift Charts (research §1).
- **API новее iOS 17 — только через `#available` с фолбэком.**
- **Скилл `swiftui-pro` считает базой iOS 27: его рекомендации проверять против правила выше.**

- **Облако** (без Xcode, без сборки): архитектура, критика, ревью диффа, Jira.
