## Итог

1. **Годится ли коннектор этой среды для конвейера:** с оговорками. Чтение, создание, комментарии с блоками кода и таблицами, правка и переходы работают, markdown не ломается, повторная авторизация в новой сессии не нужна, лишних сайтов нет. Оговорки — пункты 2 и 3.
2. **Что пришлось бы настроить:**
   - Защита от случайных записей сейчас держится только на инструкциях и дисциплине модели: запросов разрешений нет. Если нужна гарантия, правила разрешений для `mcp__Atlassian_MCP__*` (запись и переходы — `ask`, чтение — `allow`) в `.claude/settings.json`.
   - Ограничение сайтом myweather: коннектор аккаунтный, сайт один, но правило «другие сайты не трогать» нигде технически не закреплено.
   - Гарантия автора коммитов: идентичность Edward держится на переменных окружения облачного окружения; при их отсутствии автором станет `Claude <noreply@anthropic.com>`.
   - Единая форма названий типов в тикетах и скриптах: в API они по-русски («Задача», «Эпик»), в статусах — по-английски.
3. **Сюрпризы:**
   - Пишущие вызовы прошли без запросов разрешений и без push на iPhone (ответ Edward).
   - Окно Settings → Connectors показывает аккаунт, а не сессию: Xcode и Claude in Chrome там включены, но инструментов в сессии у них нет.
   - Параметр создания задачи называется `issueType` (не `issueTypeName`): первая попытка получила ошибку валидации.
   - Переход 31 называется «In Review» (по-английски), а ведёт в статус «В процессе проверки».
   - Схемы MCP занимают 107,3k токенов суммарно (21 инструмент Atlassian ≈ 24,2k). Часть из них отложена и подгружается по запросу.
   - В проекте уже была MW-1 «Тестовая задача» (Эпик, 2026-10-13), созданная вручную; её не трогали.
   - Тестовая MW-2 осталась в статусе «Готово» с меткой `harness-test-done` (удалять не требовалось).
